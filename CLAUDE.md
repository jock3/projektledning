# CLAUDE.md

Riktlinjer för Claude Code i detta projekt.

## Projektöversikt

`projektledning` är ett verktyg för att hantera projekt, uppgifter och team.

## Kodriktlinjer

- Skriv kod på svenska (variabelnamn, kommentarer) om inget annat anges
- Håll funktioner korta och fokuserade
- Inga onödiga kommentarer — koden ska vara självdokumenterande
- Testa innan du committar

## Grenstruktur

- `main` — stabil, produktionsklar kod
- `develop` — aktiv utveckling
- `feature/*` — nya funktioner
- `fix/*` — buggfixar

## Commit-konvention

```
feat: lägg till ny funktion
fix: rätta bugg i X
refactor: omstrukturera Y
docs: uppdatera dokumentation
```

## Teknisk stack

Uppdateras när stack väljs.
